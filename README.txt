ESLATMA:
Bu HTML/CSS front-end maketi. Formadagi submit hozircha tegishli ro‘yxat sahifasiga qaytaradi; ma’lumotni haqiqiy saqlash, ombor qoldig‘ini avtomatik o‘zgartirish, sotuv summasini hisoblash, rasm yuklashni ko‘rsatish uchun keyingi bosqichda JavaScript va localStorage yoki backend kerak bo‘ladi.

CSS:
